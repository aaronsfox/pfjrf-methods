# Camargo2021 Dataset

The data in this folder comes from a [publicly available dataset](https://www.epic.gatech.edu/opensource-biomechanics-camargo-et-al/) released with the paper:

**Camargo J, Ramanathan A, Flanagan W & Young A (2023). A comprehensive, open-source dataset of lower limb biomechanics in multiple conditions of stairs, ramps, and level-ground ambulation and transitions. *J Biomech*, 119: 110320. doi: [10.1016/j.jbiomech.2021.110320](https://doi.org/10.1016/j.jbiomech.2021.110320)**

Any additional use must be in line with that described in the original paper.
